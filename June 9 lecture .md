## Reducing Carboxylic Acids
- **LiAlH₄** → reduces to 1° alcohol ✓
- **NaBH₄** → cannot reduce RCOOH (only ketones/aldehydes)
- **H₂/Pt** → reduces ketones/aldehydes; also reduces C=C, C≡C; can reduce RCOOH with heat/pressure (not preferred)

## Carbonyl Reactivity — Core Concept

### Aldehydes/Ketones (no leaving group)
Nucleophile attacks C=O → tetrahedral alkoxide → picks up H⁺ → **OH product**; double bond gone

### Carboxylic Acid Derivatives (have leaving group)
Nucleophile attacks C=O → tetrahedral intermediate → LG leaves → **double bond RETAINED**, LG replaced
- RCOOH itself doesn't react with nucleophiles — it's an acid, nucleophile acts as base → deprotonation only

### Ch19 Preview (alpha-carbon chemistry)
Strong base (e.g., NaNH₂) removes α-H instead of attacking C=O → enolate → alkylation; **do NOT attack C=O**

## Carboxylic Acid Derivatives — Structures & Reactivity

### Reactivity Order (most → least reactive)
**Acid chloride > Anhydride >> Ester > Amide >> Nitrile**

| Derivative | Structure | LG |
|---|---|---|
| Acid chloride | RC(=O)Cl | Cl⁻ |
| Anhydride | RC(=O)-O-C(=O)R | RC(=O)O⁻ |
| Ester | RC(=O)OR' | R'O⁻ |
| Amide | RC(=O)NR₂ | NR₂⁻ |
| Nitrile | RC≡N | (no C=O; different rxn) |

**Why acid chloride most reactive:** Cl is highly electronegative → pulls e⁻ away → weakens bond → no resonance donation into C=O

**Why amide least reactive:** N is electron-donating → strong resonance into C=O → very stable, hard to break

**Anhydride ≈ Acid chloride:** Same reactions, different LG — anhydride LG = entire carboxylate half; treat it as just a LG that leaves

---

## Interconversion Rule
- Can only convert **down** in reactivity (more reactive → less reactive)
- Acid chloride → can make anything (anhydride, ester, amide)
- Anhydride → ester, amide only
- Ester → amide only
- Amide → nothing
- Acid chloride synthesis: RCOOH + SOCl₂ → RC(=O)Cl (**only one way**)
- Destroy any derivative back to RCOOH: add **H₂O** (+ acid and/or heat for less reactive ones)

---

## General 5-Step Mechanism (acid-catalyzed)
1. Protonation of carbonyl O (C=O + H⁺ → C=O⁺H)
2. Nucleophilic attack → tetrahedral intermediate (minus)
3. Proton transfer (remove extra H from nucleophile)
4. Reform C=O, expel LG
5. Proton transfer (deprotonate if needed)

**Base-catalyzed (no H⁺):** Skip steps 1 & 3 → only steps 2, 4, 5 → **3 steps total**

**Exception — nitrogen nucleophiles:** N always attacks first regardless of acid/base conditions (stronger nucleophile, lower activation energy)

**Never do SN2 on carbonyl carbon** (sp² carbon) — must go through tetrahedral intermediate

## Synthesis: Acid Chloride → Other Derivatives

### → Ester
- **Neutral nucleophile:** RC(=O)Cl + R'OH → RC(=O)OR' + HCl; add **pyridine** to scavenge HCl; product = all of R'OH except one H
- **Charged nucleophile:** RC(=O)Cl + R'O⁻ → RC(=O)OR'; 2-step mechanism (no proton transfer needed)
- **Fischer esterification (from RCOOH directly):** RCOOH + R'OH + H⁺ → RC(=O)OR'; acid-catalyzed → all 5 steps

### → Amide
- + NH₃ → primary amide (RC(=O)NH₂)
- + RNH₂ → secondary amide (RC(=O)NHR)
- + R₂NH → tertiary amide (RC(=O)NR₂)
- Rule: add everything except **one H** from the nitrogen nucleophile

### → Aldehyde (partial reduction)
- **LiAlH(O-t-Bu)₃** (lithium tri-tert-butoxyaluminum hydride): only 1 H available → reduces acid chloride → **aldehyde** (stops there)
- **LiAlH₄**: reduces all the way → **1° alcohol**

### → Alcohol (full reduction)
- LiAlH₄ → 1° alcohol (reduces anything: ketone, aldehyde, RCOOH, acid chloride, anhydride, ester, amide → all go to alcohol)

### → Ketone then Alcohol (Grignard)
- RC(=O)Cl + R'MgX (excess) → ketone intermediate → adds again → 3° alcohol
- Grignards react **twice** with acid chlorides; **cannot stop at ketone**

### → Ketone only (Gilman reagent)
- RC(=O)Cl + R₂CuLi (cuprate) → ketone (reacts **once only**)

---

## Summary: Acid Chloride Reactions
| Reagent | Product |
|---|---|
| H₂O | RCOOH |
| R'OH or R'O⁻ | Ester |
| NH₃ / RNH₂ / R₂NH | Primary/Secondary/Tertiary amide |
| LiAlH₄ | 1° alcohol |
| LiAlH(O-t-Bu)₃ | Aldehyde |
| R'MgX (excess) | 3° alcohol |
| R₂CuLi | Ketone |

> **Anhydrides have identical reactions** — same products, different LG
